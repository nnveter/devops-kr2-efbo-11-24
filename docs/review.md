`stats.devops.local`, порт `8003`.

| Файл, строка исходника | Дефект | Последствие | Исправление |
|---|---|---|---|
| Dockerfile:1 | `python:latest` | Новая сборка может получить несовместимую версию Python | `python:3.12-slim`, как в ПР №7 |
| Dockerfile:5–6 | Исходники копируются до установки зависимостей | Любая правка app.py сбрасывает кэш pip-слоя | Сначала requirements.txt и pip, затем app.py |
| Dockerfile:5 | `COPY . .`, нет .dockerignore | Файл .env и Git-история попадают в контекст и слои образа | .dockerignore, точечный COPY |
| .env в Git | Пароль уже опубликован | Удаление из текущего дерева не отменяет утечку в истории | `git rm --cached .env`, .gitignore, новый пароль только на VM |
| Dockerfile целиком | Нет USER | Веб-приложение работает от root | Системный пользователь app, инструкция USER |
| Dockerfile:9 | Shell-форма CMD | PID 1 — оболочка, возможны задержки доставки SIGTERM | Exec-форма JSON |
| Dockerfile:9 | Bind на 127.0.0.1 контейнера | Docker DNAT не достигает сокета приложения | Bind 0.0.0.0 внутри контейнера |
| Dockerfile:8–9 | Порт 8000 | Не соответствует варианту 3 | EXPOSE/bind/publish 8003 |
| Репозиторий | Нет .env.example | Не задокументирован способ задания секрета | Шаблон без действующего пароля |

Логика app.py и состав requirements.txt сохранены. В app.py добавляется только
разрешённый заданием комментарий с фамилией, чтобы продемонстрировать кэширование.

Действующий пароль генерируется на VM, никогда не копируется на хост и не
публикуется. Наследованный пароль шаблона больше не используется.
